# 여행 준비 웹사이트

여행 정보, 준비 체크리스트, 짐 목록, 일정, 예산을 한곳에서 관리하는 정적 웹사이트입니다.
빌드 과정 없이 `index.html`을 브라우저로 열면 동작하며, 데이터는 브라우저 localStorage에 저장됩니다.

## 동선 지도

'동선 지도' 탭에서 장소를 검색(OpenStreetMap Nominatim)하거나 지도를 클릭해 지점을 추가하면
`1. 공항 → 2. 숙소 → 3. 관광지…` 순서대로 번호 마커와 동선이 지도에 그려집니다.
순서 변경(↑↓), 이름 수정, 삭제, 구간별 직선거리 표시를 지원합니다. 지도는 Leaflet + OpenStreetMap(API 키 불필요).

## 실행

```
python3 -m http.server 8000   # http://localhost:8000
```

## 구조

- `index.html` — 화면 구조
- `style.css` — 스타일 (다크모드, 모바일 대응)
- `app.js` — 상태 관리 및 렌더링
